# Kimi 浏览器扩展（自定义提供商版）

基于官方 **Kimi 浏览器扩展 2.0.26** 的自用构建，额外支持接入任意 OpenAI 兼容的模型服务。

- 官方产品主页：<https://www.kimi.com/products/kimi-browser-extension>
- 本仓库：<https://github.com/15Soren/kimi-webbridge-extension>
- 下载：见 [Releases](https://github.com/15Soren/kimi-webbridge-extension/releases)

---

## 原版功能简介

Kimi 浏览器扩展把 Kimi 放进浏览器侧边栏，让你在浏览网页时直接对话，并让 AI 代替你操作页面。

- **侧边栏对话**：在任意网页旁与 Kimi 聊天，总结当前页面、提取信息、完成具体任务
- **浏览器操作**：打开网页、点击按钮、填写表单、滚动、截图、读取页面结构
- **任务与标签组**：一个任务对应一个标签组、一段会话，关闭标签组即结束任务
- **技能与流程录制**：用 `/` 调用内置技能；录一遍你的网页操作，让扩展记住并复用
- **划词工具**：选中文字即可翻译、解释、追问
- **本地 Agent 远程调用**：无需登录，配合 Kimi Work、Kimi Code 等本地 Agent 远程操控浏览器

详细说明以官方页面为准。

## 本版改动

### 1. 支持自定义 OpenAI 兼容提供商

原版只能使用 Kimi 账号的会员模型。本版在设置中新增「模型提供商」入口，可添加任意兼容 OpenAI 协议的服务端：

- 填写名称、Base URL、API Key
- **手动添加模型**，可添加多个
- 每个模型单独设置**上下文窗口**与**推理强度**（off / low / medium / high / xhigh / max）

保存后模型直接出现在输入框的模型菜单中，选中即可对话，推理强度按所选档位以 `reasoning_effort` 参数发送。

不请求 `/models` 接口，模型列表完全由使用者填写，因此也能用于不提供该接口的自建网关。

### 2. 关闭扩展自动更新检查

原版每 6 小时访问一次 `cdn.kimi.com/webbridge/latest/version.json` 以提示新版本。本版移除该行为：不创建定时器、启动时不再检查、并清理遗留的更新缓存，设置页不会再出现「新版本」提示。

此改动只关闭扩展自身发起的版本探测；浏览器对扩展的更新由浏览器管理。

### 3. 以补丁形式维护

所有改动集中在 `patches/custom-provider.patch`，涉及四个文件：

| 文件 | 改动 |
| --- | --- |
| `background.js` | 提供商预设、Base URL 规整、手动模型目录、模型配置透传、推理强度、关闭更新检查 |
| `chunks/sidepanel-CUbsl7eV.js` | 同一套预设逻辑、设置页提供商面板、模型菜单 |
| `chunks/i18n-pVQL_Rp2.js` | 中英文文案 |
| `assets/sidepanel-DD7JAQkM.css` | 模型行与强度按钮样式 |

官方发布新版本后，可用 `git apply` 重新应用，详见 `patches/README.md`。

## 安装

1. 从 [Releases](https://github.com/15Soren/kimi-webbridge-extension/releases) 下载 zip 并解压
2. 打开 `edge://extensions` 或 `chrome://extensions`
3. 开启「开发人员模式」
4. 点击「加载解压缩的扩展」，选择解压后的目录

若已安装商店版，请先禁用或卸载，避免两个扩展同时存在。
